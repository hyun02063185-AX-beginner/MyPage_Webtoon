# 01. 웹툰 생성기 V3 마스터 기획서

## 1. 한 문장 정의

AI·AX 개념을 일반 직장인이 쉽게 이해할 수 있는 4컷 교육 웹툰으로 제작하고, 실제 프롬프트·모델·검수 이력과 함께 MyPage 갤러리용 WebP 및 JSON으로 내보내는 개인용 제작 도구다.

## 2. 상위 목적

MyPage는 AX 전문강사의 포트폴리오다. 웹툰은 단순한 AI 이미지 전시가 아니라 어려운 개념을 쉽게 구조화하고 가르칠 수 있다는 증거다. 결과 이미지뿐 아니라 제작에 사용한 프롬프트를 공개해 방문자가 방법까지 배울 수 있는 교보재로 만든다.

## 3. 성공 기준

- 서로 다른 개념 웹툰 10편 이상을 안정적으로 완성한다.
- 모든 신규 최종본에 실제 프롬프트 전문과 모델명이 남는다.
- 검수되지 않은 이미지가 최종 export에 들어가지 않는다.
- 같은 개념을 여러 번 생성해도 이전 결과와 프롬프트가 덮어써지지 않는다.
- 최종 export가 MyPage 갤러리 규격과 정확히 일치한다.
- 외부 API 실패 후에도 기존 프로젝트, 시나리오, 이미지 이력을 열람할 수 있다.
- 앱을 새 컴퓨터로 옮길 수 있도록 DB, 이미지, export 백업 절차가 문서화된다.

## 4. 제품 경계

### 포함

- 작품 프로젝트 생성과 목록
- 구조화된 4컷 시나리오 생성·수정·버전 관리·승인
- 실제 이미지 프롬프트 조합·미리보기·저장
- 이미지 생성과 생성 시도 이력
- 한글 오타 및 시각 품질 검수
- 재생성 및 버전 비교
- 제목, imageAlt, 해설 문단 편집
- WebP 이미지와 JSON 내보내기
- 로컬 백업·복원
- 과거 이미지 선택적 가져오기

### 제외

- 공개 갤러리 페이지 개발
- MyPage 저장소 자동 배포
- 로그인, 결제, 다중 사용자 권한
- SNS 공유
- 특정 작가체 또는 기존 캐릭터 복제
- 사람 확인 없는 자동 게시

## 5. 기존 결과에서 반영한 교훈

- 검색 사전 중심 설계는 제작 도구의 핵심 목적과 맞지 않았다.
- 과거 결과에는 프롬프트와 모델이 없어 동일 스타일 재현이 불가능했다.
- 같은 slug의 결과 파일이 덮어써져 생성 이력과 실제 파일 수가 어긋났다.
- API 실패 때 모의 PNG를 성공으로 저장해 상태 신뢰성이 낮아질 수 있었다.
- 클라이언트 승인값만으로 서버가 이미지를 만들면 승인 규칙을 우회할 수 있다.
- 이미지 생성 후 한글과 배치 오류를 기록하고 재생성하는 명시적 검수 단계가 필요하다.
- PNG는 갤러리 배포에 무거우므로 WebP export가 필요하다.

## 6. 핵심 설계 원칙

1. 프로젝트, 시나리오 버전, 이미지 생성 시도, 검수, export를 서로 분리한다.
2. 모든 비용 발생 호출은 서버가 승인·잠금·멱등성을 확인한 뒤 실행한다.
3. 실제 프롬프트 스냅샷은 이미지와 같은 수준의 핵심 자산으로 다룬다.
4. 실패와 반려 결과도 삭제하지 않고 개선 이력으로 보존한다.
5. 자동 검수는 보조 수단이고 최종 결정은 사용자에게 있다.
6. 갤러리 메타데이터와 이미지 export는 검수 통과 뒤에만 만든다.
7. 새 요구사항은 ID, 수용 기준, 영향 Phase를 정의한 뒤 구현한다.

## 7. 콘텐츠 원칙

- 한국어 경어체를 기본으로 한다.
- 한 컷에는 하나의 핵심 상황과 읽기 쉬운 짧은 대사를 둔다.
- 하나의 만화는 용어 하나와 핵심 메시지 하나에 집중한다.
- 실존 인물, 브랜드 로고, 타사 서비스 UI, 개인정보를 사용하지 않는다.
- 이미지 생성 모델이 읽기 어려운 장문을 그리지 않도록 대사 길이 제한을 둔다.
- 위험한 명령어나 행동을 예시로 쓸 때는 초보자가 따라 할 가능성과 교육적 필요성을 검토한다.

## 8. 과거 자산 처리

과거 자산에 접근할 수 있다면 다음을 후보로 분류한다.

- 원본 만화 약 10편
- 공개된 생성 이미지 약 8편
- 생성 초안 약 22편
- MyPage에 실제 게시된 약 3편

가져온 자산에는 `LEGACY` 출처를 표시한다. 프롬프트가 없으면 `promptUnavailable=true`로 기록하고 추정 프롬프트를 사실처럼 저장하지 않는다. 과거 자산이 없어도 신규 개발은 계속 진행한다.
