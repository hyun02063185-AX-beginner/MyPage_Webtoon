# LIVE 이미지 생성 연결 점검 보고

작성일: 2026-09-07  
대상: 개인용 비공개 제작 도구

## 이번에 구현·확인한 범위

- 승인된 시나리오에서만 `gpt-image-2` Image API를 서버 측에서 호출한다.
- 생성 시도·최종 프롬프트·옵션·요청 식별자·안전 오류를 DB에 보존한다.
- 성공 응답은 WebP로 `storage/projects/.../source.webp`에 저장하고, 인증된 로컬 route로 프로젝트 화면에 표시한다.
- LIVE와 MOCK 화면 표기를 분리하고, MOCK 결과는 내보내기 대상으로 취급하지 않는다.
- 생성 잠금과 멱등성 키로 중복 요청을 막으며, API 실패를 MOCK 성공으로 대체하지 않는다.

## 실제 연결 결과

- 테스트 프로젝트: `API 요청과 응답`
- LIVE 요청 횟수: 1회
- 결과: `FAILED`
- 안전 오류: `API_KEY_MISSING` (당시 화면 표기; 실제 의미는 인증 또는 권한 거부)
- 공급자 요청 식별자: DB에 보존됨
- 조치: 이후 코드에서는 401/403을 `API_AUTH_FAILED`로 표시해, 키가 없다고 단정하지 않고 API 키·프로젝트 권한을 확인하도록 안내한다.

키 값 자체는 `.env.local`에 존재하며, 값은 출력하거나 저장소에 추가하지 않았다. 이 실패는 제공자 측 인증·프로젝트 권한 또는 해당 키의 이미지 API 사용 가능 상태를 확인한 뒤 재시도해야 한다.
